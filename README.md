# Vairaprabhu Portfolio

A premium personal portfolio for Vairaprabhu, a Full Stack Developer focused on React, JavaScript, Node.js and modern digital experiences for businesses and professionals.

## Project Overview

This website showcases a business-focused freelance developer identity with a premium editorial design, route-based navigation, Work/Services/About/Contact flows, WhatsApp conversion CTAs, and a production-ready React/Vite build.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React

## Folder Structure

```bash
src/
  components/
  config/
  data/
  hooks/
  pages/
  utils/
  App.jsx
  main.jsx
  index.css
public/
  resume.pdf
```

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Update contact information

Edit `src/config/contact.js`.

## Add projects

Edit `src/data/projects.js` and add project objects to the array when ready.

## Add resume

Place the PDF in `public/resume.pdf`.

## Update pricing

Adjust the pricing section in `src/pages/Home.jsx`.

## Update services

Edit `src/data/services.js`.

## Update SEO

Edit `src/config/site.js`.

## Change theme/colors

Adjust CSS variables in `src/index.css`.
